# 任务看板 — 版本更新说明

面向：**发版的人**（如何发布新版本）与 **使用者**（如何升级）。

当前分发方式为 Windows **portable 单文件**（`任务看板-x.y.z.exe`），不自动覆盖安装，需下载新文件替换旧程序。

---

## 一、使用者怎么升级

1. 打开应用 → **设置** → **关于**
2. 查看当前版本号，点击 **检查更新**
3. 若提示有新版本：
   - 阅读更新说明
   - 点击 **打开下载页**，下载新的 exe
4. **完全退出**旧程序后，用新 exe 替换（可覆盖同名文件，或换新文件名后删掉旧文件）
5. 重新打开即可；任务数据一般在本机数据目录，**不会**因换 exe 而丢失

若检查失败（网络、更新源未配置等）：向发版人索取下载链接，按上面第 4 步手动替换。

---

## 二、发版人怎么通知大家升级

### 2.1 更新源（已配置）

应用内「检查更新」会请求：

`https://raw.githubusercontent.com/ITimesGo/task-kanban/main/docs/kanban-latest.json`

对应仓库文件：`docs/kanban-latest.json`。  
改版本信息后 **提交并推送到 `main`**，用户即可查到；一般**不必**再改 `src/main/appUpdate.js` 里的 URL。

下载地址建议使用 GitHub Release 资源直链，例如：

`https://github.com/ITimesGo/task-kanban/releases/download/v1.0.1/任务看板-1.0.1.exe`

### 2.2 每次发版步骤

1. **改版本号**  
   编辑 `package.json` 的 `"version"`，例如 `"1.0.0"` → `"1.0.1"`（建议遵循 `主版本.次版本.修订号`）。

2. **打包**  
   在项目根目录执行：

   ```bash
   npm run build
   ```

   产物一般在 `dist/`，文件名类似：`任务看板-1.0.1.exe`。

3. **发 GitHub Release**  
   - 打开 https://github.com/ITimesGo/task-kanban/releases/new  
   - Tag：`v1.0.1`（与版本一致）  
   - 上传 `dist/任务看板-1.0.1.exe`  
   - Publish release  

4. **更新 feed JSON**  
   编辑 `docs/kanban-latest.json`：

   ```json
   {
     "version": "1.0.1",
     "notes": "本次更新说明",
     "url": "https://github.com/ITimesGo/task-kanban/releases/download/v1.0.1/任务看板-1.0.1.exe"
   }
   ```

   然后提交并推送到 `main`：

   ```bash
   git add docs/kanban-latest.json package.json
   git commit -m "chore: release 1.0.1"
   git push
   ```

5. **通知用户**（可选）  
   群公告 / 邮件：说明新版本号，并提示到 **设置 → 关于 → 检查更新**。

### 2.3 版本比较规则

- 按 `主.次.修订` 数字比较（可带前缀 `v`，如 `v1.0.1`）。
- 仅当远程 `version` **高于** 本地版本时提示「发现新版本」。
- 相等或远程更低：显示「已是最新版本」。

## 三、自测清单

发版后建议自己验证一遍：

- [ ] 旧版（版本号更低）打开 → 设置 → 关于 → 检查更新 → 出现新版本与「打开下载页」
- [ ] 点「打开下载页」能打开正确链接
- [ ] 用新版再检查 → 显示已是最新
- [ ] 故意写错 JSON / 关掉网络 → 有明确错误提示，程序不崩

---

## 四、注意

- **数据安全**：升级只换程序文件；数据在应用数据目录。重大变更若涉及数据格式，应在 `notes` 里写清楚，并尽量保持向后兼容。
- **不自动覆盖**：当前不做静默安装/自动替换，避免 portable 场景下误伤用户文件。
- **raw 访问**：若部分网络打不开 `raw.githubusercontent.com`，检查更新会失败，但仍可通过 Release 页面手动下载。
