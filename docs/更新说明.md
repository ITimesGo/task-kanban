# 任务看板 — 版本更新说明

当前正式通道为 Windows **NSIS 安装版** + **electron-updater**（与常见桌面软件相同：下载更新 → 退出安装 → 自动打开新版本）。

> **可复用总手册（给其他项目照做）**：[`docs/electron-windows-auto-update-playbook.md`](./electron-windows-auto-update-playbook.md)

---

## 一、使用者怎么升级

### 已安装「安装版」（推荐）

1. 打开应用 → **设置** → **关于**
2. 点击 **检查更新**
3. 有新版本时点 **立即更新**
4. 等待下载；完成后程序会退出、安装并**自动重新打开**（即为新版本）

数据与插件在 `%APPDATA%\任务看板`，一般不会因升级丢失。

### 仍在使用旧便携版（portable 单文件）

便携版无法安全地「覆盖自己并安装」。请：

1. 从 GitHub Release 下载 `task-kanban-setup-*.exe`
2. 运行安装（可装到默认目录）
3. 之后用开始菜单/桌面快捷方式打开，即可使用自动更新
