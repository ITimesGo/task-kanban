# 发版（简易）

仓库：https://github.com/ITimesGo/task-kanban  

使用 **NSIS 安装版 + electron-updater** 自动更新（下载 → 退出安装 → 自动打开新版本）。

其他 Electron 项目若要复用整套方案（配置模板、图标坑、静默升级、验收清单），见：  
[`docs/electron-windows-auto-update-playbook.md`](./electron-windows-auto-update-playbook.md)

---

## 发一版要做的事

### 1. 改版本号
编辑 `package.json` 的 `"version"`，例如 `"1.1.5"` → `"1.1.6"`。

### 2. 本地打包

```powershell
npm run build
```

生成（在 `dist/`）：

- `task-kanban-setup-1.1.6.exe` — 安装包（给用户）
- `latest.yml` — **必须**一并上传，否则应用内检查更新会失败
- `task-kanban-setup-1.1.6.exe.blockmap` — 差量更新用（建议一并上传；不传也能整包更新）

### 3. 提交并推送

```powershell
git add package.json
git commit -m "chore: release 1.1.6"
git push
```

### 4. 发布 GitHub Release
1. 打开 https://github.com/ITimesGo/task-kanban/releases/new  
2. Tag：`v1.1.6`（Create new tag）  
3. 标题：`任务看板 v1.1.6`  
4. **Release 说明（正文）**：写清本版更新点（每行一条，可用 `-` 开头）。应用内「关于」会列出这些内容。  
5. 上传附件：
   - `dist/task-kanban-setup-1.1.6.exe`（必传）
   - `dist/latest.yml`（必传）
   - `dist/task-kanban-setup-1.1.6.exe.blockmap`（建议传）
6. Publish release  

### 5. 用户侧
- **首次**：运行 setup 安装（会生成开始菜单/桌面快捷方式）  
- **之后**：设置 → 关于 → 检查更新 → 立即更新 → 自动重启即新版本  

> 旧的 portable 单文件（`task-kanban-x.y.z.exe`）**不能**自动安装更新，需改装一次 setup。

---

## 核对清单

- [ ] `package.json` version 已改  
- [ ] `npm run build` 成功  
- [ ] Release 附件同时有 **setup exe** 和 **latest.yml**  
- [ ] 用安装版打开 → 检查更新 → 立即更新 → 能自动重启到新版本  

---

## 注意

- 任务/插件数据在 `%APPDATA%\任务看板`，换安装包一般不丢。  
- 不要用中文文件名上传附件。
