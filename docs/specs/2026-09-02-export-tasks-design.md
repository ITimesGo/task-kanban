# 任务导出设计

## 目标
按标签筛选任务，按时间排序，导出为 PDF / Markdown / HTML。

## 入口
设置 → 导出

## 选项
- 标签：多选（空 = 全部；命中任一标签）
- 状态：全部 / 待执行 / 已执行
- 排序：创建时间 / 状态时间 / 更新时间（新→旧）
- 格式：PDF（默认）/ Markdown / HTML
- 内容：始终含正文、标签、时间、状态；可选「包含图片」

## 实现
- 主进程 `exportTasks.js` 筛选、渲染、写文件
- PDF：隐藏窗口 `printToPDF`
- HTML/MD：另存为；含图时 HTML 用 base64，MD 旁建 `_assets` 目录
