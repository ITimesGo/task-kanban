# 媒体类型筛选（图片 / 视频 / 附件）

## 目标
在二级筛选行增加「图片 / 视频 / 附件」多选胶囊，按 **任一匹配（OR）** 过滤任务列表。

## 交互
- 位置：`#toolbarSecondary`（排序、时间范围旁）下拉多选
- 触发器文案：未选「媒体类型」；已选显示名称（如「图片、视频」）
- 下拉内勾选：图片 / 视频 / 附件；未选 = 不限；选中后取并集（OR）
- 与状态、标签、时间、搜索叠加（彼此 AND）
- 计入筛选角标；「恢复默认」清空媒体筛选
- 不写入启动默认视图

## 判定
- **图片**：任务 `media`/`images` 或正文 doc 含 `image` 节点
- **视频**：任务 `media`/`videos` 或正文 doc 含 `video` 节点
- **附件**：`attachments.length > 0`

## 非目标
- 不改为单选分段
- 不要求同时满足（AND）
